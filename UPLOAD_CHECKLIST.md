# GitHub upload checklist

Upload these items:

- `assets/` — dashboard and representative openLCA result screenshots
- `databricks/` — clean SQL scripts only
- `data/` — small derived CSV summaries
- `openlca/exports/` — exported result workbooks for S06-S08
- `docs/` — methodology notes
- `LICENSE_NOTE.md`

Do not upload:

- BAFU/ecoinvent/openLCA database packages
- access tokens, Databricks credentials, server secrets, or PATs
- raw proprietary reports or licensed third-party files unless redistribution is clearly permitted
- temporary screenshots showing credentials or account identifiers
